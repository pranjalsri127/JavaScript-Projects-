# 🚀 JavaScript Projects for Beginners

This repository contains a collection of **beginner-friendly JavaScript projects** built using **HTML, CSS, and Vanilla JavaScript**.  
The goal of this repo is to strengthen core JavaScript concepts by building small, practical projects instead of only reading theory.

All projects are organized into **three difficulty levels**, starting from absolute basics and gradually moving toward more logic-heavy applications.
